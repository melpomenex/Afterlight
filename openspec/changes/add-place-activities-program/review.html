What the repository changes in this plan

The manifest is already plain data, but Phoenix needs its exported projection updated too. Place controllers must compose with the theater adapter. The existing WebGPU fast path is harness-only. Gardens/economy P6 remains unfinished and independent.

Defaults and follow-on ideas to review

This draft commits to all six phases with bounded first-release game rules. Optional expansions remain follow-ons: linked racing cabinets, table tennis/doubles, extra board/card games, advanced pool shots, larger curling teams and additional arcade titles. Review the design’s final section for the complete retained list.

Pool uses explicit casual house rules. Disconnect grace is 30 seconds. Owner failure aborts live matches. Tournament v1 is room-local pool for four or eight people. These are proposed defaults, not shipped behavior.
